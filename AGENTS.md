# Команды для агентов и разработчиков

Требуется **Node.js ≥ 22** (см. `.nvmrc` и `engines` в `package.json`).

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Dev-сервер по умолчанию: http://localhost:5173

## Линтинг

```bash
npm run lint
```

Базовый ESLint flat config; полная настройка из `linting.zip` — в issue #14.

## Сборка

```bash
npm run build
```

## Preview production-сборки

```bash
npm run preview
```
