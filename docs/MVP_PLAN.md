# План MVP

Чеклист этапов приложения «Архив погоды» (источник: MVP #21).

## Этапы

- [x] **Этап 0 — Bootstrap** (#22): Vite + React + TS + Ant Design (`ru_RU`) + PWA-каркас + ESLint/Prettier + документация пайплайна.
- [x] **Этап 1 — Выбор города и геолокация** (#23): autocomplete через Open-Meteo Geocoding (`language=ru`), кнопка «Моё местоположение» с fallback на ручной поиск, сохранение `{ name, lat, lon }` в состоянии приложения.
- [x] **Этап 2 — Выбор якорной даты** (#24): DatePicker одной даты, валидация календарных дат (в т.ч. 29.02), хранение anchor date в состоянии, расчёт диапазона `anchorYear − 10 … anchorYear + 10`.
- [x] **Этап 3 — API-слой Open-Meteo Archive** (#25): загрузка архива, нормализация, кэш, правило «+10 лет — только исторические годы».
- [x] **Этап 4 — Режим A** (#26): таблица по годам для выбранной даты (t° min/max, осадки, ветер, облачность).
- [ ] **Этап 5 — Режим B** (#27): год × неделя вокруг даты (таблица дней внутри строки года).
- [ ] **Этап 6 — PWA offline** (#28): offline-стратегии для кэширования данных API.

## Критерии этапа 2

- DatePicker на русском; пользователь выбирает одну якорную дату.
- Дата отображается в UI и хранится в React state (`useWeatherAppState`).
- Из якорной даты вычисляется диапазон ±10 лет; утилиты доступны для API-слоя (#25) и режимов A/B.
- Якорь 29.02 допустим; `isValidCalendarDate` возвращает false для невисокосных годов (отображение «нет данных» — в #26/#27).
- `npm run lint` и `npm run build` проходят.

## Критерии этапа 3

- `fetchModeA` / `fetchModeB` возвращают нормализованные записи по `(lat, lon, anchorDate)`.
- Диапазон `anchorYear ± 10`; будущие даты и ERA5-lag (~5 дней) — `hasData: false`, без Forecast API.
- 29.02 в невисокосные годы — режим A: одна запись `feb29`, без HTTP;
  режим B: `feb29` только на отсутствующую календарную дату в окне,
  остальные дни — нормализация из Archive API.
- In-memory cache и параллелизм 3–5 запросов для режима B.
- `npm run lint` и `npm run build` проходят.

## Критерии этапа 4

- Переключатель режимов A/B на одной странице; режим B — заглушка до #27.
- Таблица до 21 строки (годы `anchorYear ± 10`): t° min/max, осадки (тип + мм), ветер, иконка облачности.
- Состояния loading / error / empty / «нет данных» для отдельных годов.
- Будущие годы без архива — «—» / «нет данных», без прогноза.
- Все тексты на русском; `npm run lint` и `npm run build` проходят.
