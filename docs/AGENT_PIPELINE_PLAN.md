## Правила PR

- Ветка: `issue/<номер>-краткое-имя` от актуального `main` (или от head PR родителя для дочерних задач).
- Тело PR содержит `Fixes #<номер>`.
- Документация обновляется в том же PR.
- Не мержить в `main` автоматически — только человек.
