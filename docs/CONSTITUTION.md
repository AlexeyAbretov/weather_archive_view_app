## Назначение

PWA-приложение для просмотра архива погоды по выбранному городу и дате.

## Принципы

1. **Язык UI** — только русский (`ru_RU`).
2. **Источник данных** — [Open-Meteo Archive API](https://open-meteo.com/en/docs/historical-weather-api).
3. **Режимы отображения** — A (таблица по годам для одной даты) и B (год × неделя вокруг даты).
4. **Лицензия API** — non-commercial use согласно условиям Open-Meteo.
5. **MVP** — без деплоя в production; локальная разработка и сборка.
6. **Стек** — Vite, React, TypeScript, Ant Design, PWA (`vite-plugin-pwa`).
7. **Линтинг** — vendored `@llm/linting` (Node ≥ 22).

## Ограничения

- Будущие даты в диапазоне «+10 лет» — только исторические годы (без прогноза).
- Не коммитить `.env` и секреты.
