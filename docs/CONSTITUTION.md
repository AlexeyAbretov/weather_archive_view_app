# Конституция MVP

Источник требований: [MVP #11](https://github.com/AlexeyAbretov/weather_archive_view_app/issues/11).

## Продукт

PWA для просмотра **архива погоды** за выбранный календарный день по годам. Два режима отображения:

- **Режим A** — таблица «год × метрики» за один день.
- **Режим B** — expandable rows по годам с окном ±7 дней вокруг выбранной даты.

## Стек

- React 18, TypeScript, Vite
- Ant Design (UI, локаль `ru_RU`)
- Open-Meteo Archive API (geocoding + archive)

## UI и язык

- Интерфейс **только на русском** (Ant Design locale, тексты, форматирование дат через `dayjs` с локалью `ru`).

## Бизнес-правила

- «Будущие» даты в окне +10 лет от сегодня — только **исторические годы**, без прогноза.
- Выбор города через поиск (geocoding) и опционально геолокацию браузера.

## Границы MVP (out of scope)

- Офлайн-кеш погодных данных (кроме базового PWA shell на этапе 5).
- IP-geolocation fallback.
- Аутентификация, аккаунты, push-уведомления.
- Прогноз погоды на будущие даты.

## PWA и деплой

- Manifest и service worker через `vite-plugin-pwa`.
- В production PWA требует HTTPS; для локальной разработки достаточно `localhost`.

## Изменения конституции

Конституция фиксирует неизменяемые принципы MVP. Изменения — только через явное согласование с владельцем продукта и обновление issue #11.
