# Пайплайн агентов

Оркестрация разработки MVP через GitHub Issues и Pull Requests.

## Роли

1. **Аналитик** — разбор issue, план в комментарии, метка `ready-for-dev`.
2. **Разработчик** — реализация, документация в том же PR, метка `in-dev` → PR на review.
3. **QA** — проверка по чеклисту этапа, `fix-round` при необходимости.

## Метки

| Метка | Назначение |
|-------|------------|
| `feature` / `bug` | Тип задачи |
| `needs-plan` | Ожидает аналитика |
| `ready-for-dev` | План готов, можно брать в работу |
| `in-dev` | В разработке |
| `needs-human` | Требуется решение человека |
| `fix-round:N` | Раунд исправлений после QA |

## Правила PR

- В теле PR обязательна строка `Fixes #<номер issue>` (или `Related to` для зависимых задач).
- Документация обновляется **в том же PR**, что и код.
- Чеклисты в [MVP_PLAN.md](./MVP_PLAN.md) — отмечать `[x]` только за выполненные в этом PR пункты.
- Не мержить в `main` без прохождения QA (оркестратор).
- Не коммитить `.env` и секреты.

## Ветки

- `issue/<номер>-краткое-имя` — от актуального `main` (или от head PR родителя для дочерних задач).
- Язык коммитов и описаний PR — **русский**; код — TypeScript по [CONSTITUTION.md](./CONSTITUTION.md).

## Команды разработки

См. [AGENTS.md](../AGENTS.md): `npm install`, `npm run dev`, `npm run lint`, `npm run build`.
